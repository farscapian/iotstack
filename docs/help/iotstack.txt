iotstack -- Build, deploy, and maintain your Internet of Things Stack

Command-line tool for building, flashing, and maintaining an ESPHome device
fleet. Discovers devices on the network, compiles firmware, runs OTA updates,
and integrates with Home Assistant and Matter commissioning workflows. Deploy 
one or more OpenThread Border Routers to support your Thread Network.

Commands:

  update              Compile and flash device(s) over-the-air (OTA)
  reassign            Flash specific devices to a different configuration
  verify              Check if devices match the current build hash
  verify-flash        Compare on-device flash checksums to build artifacts (USB)
  flash               Flash device via serial/USB (for bricked devices)
  logs                Stream device logs (serial, or over the network by role)
  query               Query Home Assistant device and entity registry
  devices             Show discovered ESPHome devices on network (production
                      and bootstrap by default; use --production or --bootstrap)
  bootstrap            Alias for: iotstack devices --bootstrap
  device              Read per-device NVS secrets from USB-connected hardware
  roles               Show available device roles and their configurations
  secret              Retrieve secrets from encrypted pass store
  matter              Matter commissioning (commission, configure-trust-store)
  otbr                OpenThread Border Router provisioning (flash, vm, snap, docker)
  rotate-secrets      Rotate device secrets (OTA password and API key)
  clean               Clean compilation caches, logs, and artifacts
  tests               Run overnight integration tests (USB ESP32-C6)

Use 'iotstack <command> help' for detailed help on any command.
Use 'iotstack help <role>' for per-device flash / update / reassign / verify
help (docs/help/roles/<role>.txt).

Global Options (valid anywhere on the command line, before or after the subcommand):
  -v, --verbose       Show all output (compiler, flashing, diagnostics); --verbose
                      is a full alias for -v (incompatible with -q/--quiet)
  -q, --quiet         Suppress status messages (errors still shown; incompatible
                      with -v/--verbose)
  --create-log        Copy console output to ~/.iotstack/logs/iotstack-<cmd>.log
                      in real time (implies --timestamp; console stays live; log
                      lines include source: iotstack.sh, esptool, serial:<chip>:<tty>)
  --log-id=<id>       Write to ~/.iotstack/logs/iotstack-<id>.log (implies
                      --create-log and -v; .log suffix optional, e.g. flash-0 or
                      flash-0.log). Reusing the same id appends later runs across
                      any subcommand; a new id starts a new log file
  --timestamp         Prefix each console line with an ISO datetime (iotstack status
                      messages and subprocess output) to show timing during long runs
                      (enabled automatically by --create-log)
