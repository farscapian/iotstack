iotstack — Manage ESPHome devices

Command-line tool for building, flashing, and maintaining an ESPHome device
fleet. Discovers devices on the network, compiles firmware, runs OTA updates,
and integrates with Home Assistant and Matter commissioning workflows.

Global Options:
  -v, --verbose       Show all output (compiler, flashing, diagnostics)
  -q, --quiet         Suppress status messages (errors still shown)

Usage:
  iotstack [-v|--verbose] [-q|--quiet] <command> [options]
  iotstack update [options] [<device>|<yaml>|all]
  iotstack verify [<device>|<yaml>|all]
  iotstack reassign <MAC1> [MAC2 ...] <device|yaml> [--ota-password PASSWORD]
  iotstack flash <device|yaml> [tty-device]
  iotstack logs [-f] <tty-device>|[<MAC>] <role>
  iotstack set-boot <device> <failsafe|production>
  iotstack matter commission <qr-image>|<manual-pairing-code>
  iotstack matter configure-trust-store [pairing-code]
  iotstack otbr flash /dev/sdX
  iotstack otbr logs -f <hostname>

Matter files: ~/.iotstack/chip-tool/ (snap: symlink to ~/snap/chip-tool)
OTBR data: ~/.otbrstack/ (env files in ~/.otbrstack/env/)
  iotstack devices [role|other] [--id]
  iotstack roles
  iotstack secret get <role> <ota|api> [version]
  iotstack rotate-secrets <role> [new-password]
  iotstack clean
  iotstack help [command]

Examples:
  iotstack -v flash bleproxy /dev/ttyACM0    # Flash with verbose output
  iotstack --verbose update all              # Update all devices, show details
  iotstack -q roles                          # Quiet output (just role names)
  iotstack --quiet clean                     # Silent cleanup

Commands:

  update              Compile and flash device(s) over-the-air (OTA)
  reassign            Flash specific devices to a different configuration
  verify              Check if devices match the current build hash
  flash               Flash device via serial/USB (for bricked devices)
  logs                Stream device logs (serial, or over the network by role)
  query               Query Home Assistant device and entity registry
  devices             Show discovered ESPHome devices on network
  roles               Show available device roles and their configurations
  secret              Retrieve secrets from encrypted pass store
  matter              Matter commissioning (commission, configure-trust-store)
  otbr                OpenThread Border Router provisioning (flash, vm, snap, docker)
  rotate-secrets      Rotate device secrets (OTA password and API key)
  clean               Clean build artifacts and compilation caches
  help                Show help for a command

Use 'iotstack <command> help' for detailed help on any command.
