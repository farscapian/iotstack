iotstack — Build, deploy, and maintain your Internet of Things Stack

Command-line tool for building, flashing, and maintaining an ESPHome device
fleet. Discovers devices on the network, compiles firmware, runs OTA updates,
and integrates with Home Assistant and Matter commissioning workflows. Deploy 
one or more OpenThread Border Routers to support your Thread Network.

Commands:

  update              Compile and flash device(s) over-the-air (OTA)
  reassign            Flash specific devices to a different configuration
  verify              Check if devices match the current build hash
  flash               Flash device via serial/USB (for bricked devices)
  logs                Stream device logs (serial, or over the network by role)
  query               Query Home Assistant device and entity registry
  devices             Show discovered ESPHome devices on network
  roles               Show available device roles and their configurations
  secret              Retrieve secrets from encrypted pass store
  matter              Matter commissioning (commission, configure-trust-store)
  otbr                OpenThread Border Router provisioning (flash, vm, snap, docker)
  rotate-secrets      Rotate device secrets (OTA password and API key)
  clean               Clean build artifacts and compilation caches

Use 'iotstack <command> help' for detailed help on any command.

Global Options:
  -v, --verbose       Show all output (compiler, flashing, diagnostics)
  -q, --quiet         Suppress status messages (errors still shown)
