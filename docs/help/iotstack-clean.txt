iotstack clean -- Clean iotstack caches and runtime artifacts

Removes the iotstack compilation cache, session logs, and runtime artifacts under
~/.iotstack/. Does not delete ESPHome build output (yamls/.esphome/ or anything
under ~/.esphome/) or PlatformIO's shared cache (~/.platformio/.cache/). Safe to
rerun; it never deletes source YAMLs. Use when you need to clear iotstack caches
or reclaim log/artifact disk space. The partition table CSV is regenerated on the
next compile after artifacts are removed.

Removes:
  - Compilation cache file (~/.iotstack/compilation-cache.csv)
  - Logs directory (~/.iotstack/logs/); with --create-log / --log-id the session
    log is written after cleanup finishes
  - Artifacts directory (~/.iotstack/artifacts/), including partition table CSV
  - Temporary YAML files under yamls/ (.temp-compile-*, .iotstack-bootstrap-*.yaml,
    .temp-ota-upload-*, and related gitignored runtime copies)

Preserves:
  - ESPHome project build output (yamls/.esphome/)
  - ESPHome user data (~/.esphome/)
  - PlatformIO cache (~/.platformio/.cache/)

Usage:
  iotstack clean

Examples:
  iotstack clean                    # Clean iotstack caches, logs, and artifacts
  iotstack -v clean                 # Verbose output
