iotstack clean -- Clean build artifacts and compilation caches

Removes generated build output, compiler caches, session logs, and runtime
artifacts. Safe to rerun; it never deletes source files. Use when you need a
full rebuild or to reclaim disk space. The partition table CSV is regenerated on
the next compile.

Removes:
  - ESPHome build directory (.esphome/build/)
  - ESPHome storage (~/.esphome/storage/)
  - ESPHome IDE data (~/.esphome/idedata/)
  - PlatformIO cache
  - Compilation cache file
  - Logs directory (~/.iotstack/logs/); with --create-log / --log-id the session
    log is written after cleanup finishes
  - Artifacts directory (~/.iotstack/artifacts/), including partition table CSV

Usage:
  iotstack clean

Examples:
  iotstack clean                    # Clean all build artifacts
  iotstack -v clean                 # Verbose output
