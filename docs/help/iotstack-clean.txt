iotstack clean — Clean build artifacts and compilation caches

Removes generated build output, compiler caches, and session logs. Safe to rerun;
it never deletes source files. Use when you need a full rebuild or to reclaim
disk space.

Removes:
  - ESPHome build directory (.esphome/build/)
  - ESPHome storage (~/.esphome/storage/)
  - ESPHome IDE data (~/.esphome/idedata/)
  - PlatformIO cache
  - Compilation cache file
  - Logs directory (~/.iotstack/logs/)
  - Temporary artifact files (partition table CSV is kept)

Usage:
  iotstack clean

Examples:
  iotstack clean                    # Clean all build artifacts
  iotstack -v clean                 # Verbose output
