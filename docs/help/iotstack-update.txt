iotstack update — Compile and flash device(s) over-the-air (OTA)

Compiles firmware and flashes it to ESPHome devices over the network. Detects
which devices need updates by build hash and can update by role, MAC, or all at
once in parallel.

Usage:
  iotstack update [options] [<device>|<yaml>|all]
  iotstack update [options] [<MAC1> [MAC2 ...]] <device|yaml>

Arguments:
  <device>      Device role (e.g., bleproxy, mmwave)
  <yaml>        Path to device config (e.g., yamls/bleproxy.yaml)
  all           Update all device configs in the project
  <MAC1> [MAC2...]  MAC suffix(es) to update (6 hex digits each)

Options:
  --ota-password <pwd>  OTA password for device authentication
  --dry-run             Compile and show what would be flashed (no flash)
  --force-reflash       Flash all devices regardless of version
  --jobs N              Max concurrent OTA jobs (default: 4)

  -v, --verbose is a global flag (anywhere on the command line); shows full
  compilation output for update. Example: iotstack -v update bleproxy

Per-role help (flash, update, reassign, verify share one file per role):

  iotstack help matrixdisplay
  iotstack update matrixdisplay help

Examples:
  iotstack update bleproxy                           # All bleproxy devices
  iotstack update all                                # All devices
  iotstack update --dry-run mmwave                   # Preview, no flash
  iotstack update --force-reflash bleproxy           # Flash, ignore version
  iotstack update --jobs 8 bleproxy                  # 8 parallel OTA jobs
  iotstack update a1a7b0 8e1aa8 bleproxy             # Specific devices by MAC
  iotstack update 135b60 1a7b00 1af95c threadrouter  # 3 specific Thread devices
  iotstack update bleproxy --ota-password <pwd>      # Update with OTA password
