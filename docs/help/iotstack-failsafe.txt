iotstack failsafe — Show devices running failsafe (recovery) firmware

Lists devices advertising the failsafe mDNS service (_iotstack-failsafe._tcp).
These are devices currently booted into the failsafe/recovery partition, not
production firmware.

Production devices (e.g. matrixdisplay-8238cc) are listed by:
  iotstack devices

Usage:
  iotstack failsafe [--json] [--id] [--csv]

Options:
  --id        Output only device MAC suffixes (space-separated)
  --csv       CSV output
  --json      JSON output

Examples:
  iotstack failsafe              # Table of failsafe devices on the network
  iotstack failsafe --id         # MAC suffixes only (for scripts)
  iotstack flash failsafe /dev/ttyACM0   # Flash failsafe image via serial
