iotstack query — Query Home Assistant device and entity registry

Lists devices and entities in Home Assistant via the WebSocket API. Optionally
filter to one device to see its sensors, switches, buttons, and other entities.

Usage:
  iotstack query [<device-name>|--list]

Arguments:
  <device-name>  Device name to query (e.g., "Kitchen RoomRemote")
  --list, -l     List all devices in Home Assistant

Examples:
  iotstack query --list                             # List all HA devices
  iotstack query "Kitchen RoomRemote"               # Query one device by name
  iotstack query "Bilresa5 - Secondary RoomRemote"  # Quote names with spaces

For detailed help including setup and dependencies, see:
