iotstack devices — Show discovered ESPHome devices on network

Lists ESPHome devices visible on the network via mDNS. Optionally filter by
role or show devices that do not match any configured role.

Usage:
  iotstack devices [role|other] [--id]

Arguments:
  [role]        Show only devices matching this role (e.g., bleproxy, mmwave)
  [other]       Show only devices that don't match any defined role
  [--id]        Output only device IDs (space-separated, useful for scripts)

Examples:
  iotstack devices                # Show all discovered devices
  iotstack devices bleproxy       # Show only bleproxy devices
  iotstack devices other          # Devices not matching any role
  iotstack devices --id           # Output all device IDs
  iotstack devices bleproxy --id  # Output bleproxy device IDs
  iotstack devices other --id     # Output IDs of unmatched devices
