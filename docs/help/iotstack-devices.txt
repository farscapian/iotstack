iotstack devices -- Show discovered ESPHome devices on network

Lists ESPHome devices visible on the network via mDNS, then verifies each
candidate is online with a TCP port check before listing (production: port 6053;
bootstrap: port 3232 or 6053; 2 second timeout per probe). Stale avahi-daemon
cache entries for powered-off devices are omitted. By default shows both production and bootstrap (recovery)
devices. Optionally filter by role or partition.

Usage:
  iotstack devices [role|other] [--production|--bootstrap] [--json] [--id] [--csv]

Arguments:
  [role]        Show only production devices matching this role (e.g., bleproxy)
  [other]       Show only production devices that don't match any defined role
  [--id]        Output only device IDs (space-separated, useful for scripts)

Options:
  --production  Show only production devices (_esphomelib._tcp)
  --bootstrap   Show only bootstrap/recovery devices (_iotstack-bootstrap._tcp)

  With no partition flag, both production and bootstrap are listed. Bootstrap
  rows are omitted when the same MAC already appears on live production.
  Role filters apply to production devices only; bootstrap hosts are always
  included when listing both partitions (if they pass the TCP liveness check).

  Image hashes: devices advertise bootstrap_image_hash and production_image_hash
  in mDNS TXT (_iotstack-bootstrap._tcp, _iotstack-meta._tcp, and config_hash on
  _esphomelib._tcp). iotstack devices shows both columns per device.

Examples:
  iotstack devices                      # Production + bootstrap (default)
  iotstack devices --production         # Production devices only
  iotstack devices --bootstrap          # Bootstrap devices only
  iotstack devices bleproxy             # bleproxy production + any bootstrap
  iotstack devices bleproxy --production
  iotstack devices other                # Non-role production + any bootstrap
  iotstack devices --id                 # Unique MAC suffixes (prod + bootstrap)
  iotstack devices --production --id    # Production device IDs only

Backward compatibility:
  iotstack bootstrap                    # Same as: iotstack devices --bootstrap
