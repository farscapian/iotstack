iotstack reassign — Flash specific devices to a different configuration

Flashes one or more devices (by MAC address) to a different role or YAML config
and updates Home Assistant entity IDs to match. Other devices on the network are
left unchanged.

Usage:
  iotstack reassign <MAC1> [MAC2 ...] <device|yaml> [options]

Arguments:
  <MAC1> [MAC2 ...]  MAC suffix(es) to reassign (e.g., 19b164 199ef4)
  <device|yaml>      Target device role or YAML config

Options:
  --ota-password <pwd>
                  Single OTA password for device authentication
  --ota-password-list-path <file>
                  File with list of passwords to try (one per line)

Examples:
  iotstack reassign 19b164 bleproxy           # Reassign to bleproxy role
  iotstack reassign 8dfcac 0f4df4 mmwave      # Reassign several to mmwave
  iotstack reassign 11cdc4 threadrouter       # Reassign to a Thread device
  iotstack reassign 19b164 yamls/custom.yaml  # Reassign to a custom YAML

  # With an explicit OTA password:
  iotstack reassign 19b164 mmwave --ota-password <pwd>

  # Try multiple passwords (one per line) when the current one is unknown:
  iotstack reassign 19b164 threadrouter --ota-password-list-path passwords.txt

PASSWORD LIST FILE FORMAT:
  - One password per line
  - No spaces or quotes
  - Empty lines and lines starting with # are ignored
  - Example (passwords.txt):
    myPassword123
    anotherPassword456
    # Old password, probably not used
    oldPassword789
