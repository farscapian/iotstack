iotstack commission — Deprecated alias for matter commission

Same as iotstack matter commission: commissions a Matter device onto Thread
from a QR image or pairing code, then hands it off to Home Assistant. Prefer
iotstack matter commission for new use.

Required secrets (stored in pass):
  iotstack/common/thread_tlv          Thread network TLV data (hex)
  iotstack/common/ha_url              Home Assistant URL
  iotstack/common/ha_token            Home Assistant long-lived token

Set secrets with:
  pass insert iotstack/common/thread_tlv
  pass insert iotstack/common/ha_url
  pass insert iotstack/common/ha_token

chip-tool / Matter files (non-secret) under ~/.iotstack/chip-tool/
  common/        fabric storage
  common/trust/  attestation PAA/CD certs
  paa-mirror/    vendor PAA index cache

Dependencies:
  - zbar-tools (zbarimg): apt install zbar-tools
  - chip-tool: https://github.com/project-chip/connectedhomeip
  - curl, python3

Usage:
  iotstack commission <path-to-qr-image>
  iotstack commission <manual-pairing-code>

How to use (QR image):
  1. Take a photo of the Matter QR code (phone, screenshot, etc.)
  2. Save the image (JPG, PNG, etc.)
  3. Run: iotstack commission /path/to/image.jpg

How to use (manual pairing code):
  1. Read the pairing code from the device label or packaging
  2. Run: iotstack commission 0000-000-0000

Examples:
  iotstack commission ~/qr-code.jpg
  iotstack commission ~/Downloads/device-qr.png
  iotstack commission 1234-567-8901
