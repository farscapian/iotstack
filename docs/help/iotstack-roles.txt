iotstack roles — Show available device roles and their configurations

Lists device roles defined in this project and the YAML file each role uses.
Shows WiFi and Thread variants so you can see what firmware types are available.

Usage:
  iotstack roles [--json] [--id] [--csv]

Examples:
  iotstack roles                  # Show all available device roles
  iotstack roles --json           # JSON array of role objects (via jq)
  iotstack roles --json --id      # JSON array of role name strings

Output shows:
  - Role name (e.g., bleproxy, mmwave, threadrouter)
  - Network type (WiFi or Thread)
  - YAML configuration path
  - Number of devices currently running each role

Per-role command help (flash, update, reassign, verify):

  iotstack help <role>           e.g. iotstack help matrixdisplay
  iotstack flash <role> help     same docs/help/roles/<role>.txt file
  iotstack update <role> help
  iotstack reassign help <role>
