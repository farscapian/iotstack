iotstack flash — Serial flash tool for device setup and recovery

Flashes firmware over USB/serial when OTA is unavailable or for initial setup.
Fresh devices get recovery and production partitions; existing devices can receive
an OTA-style update over serial.

Usage:
  iotstack flash <device> [tty-device] [options]
  iotstack flash failsafe [tty-device|role]

Arguments:
  <device>        Device role (e.g., bleproxy, mmwave, threadrouter)
  failsafe        Flash failsafe image via serial
  [tty-device]    Serial device (e.g., /dev/ttyACM0). Auto-detected if
                  omitted.
  [role]          Production role for dual-flash (e.g., mmwave, bleproxy)

Options:
  --ota-only      Skip failsafe flash, only OTA production (device already
                  has recovery)
  --flash-anyway  Always erase and reflash (skip hash comparison)

Smart flash (default):
  Serial erase runs only when the on-device partition table or failsafe
  image differs from the current build. If both match, the failsafe
  partition is left intact. Production OTA is skipped when the production
  partition already matches the compiled image.

Examples:
  iotstack flash bleproxy /dev/ttyUSB0           # Smart setup (recovery + prod)
  iotstack flash failsafe mmwave                 # Dual-flash: failsafe + mmwave
  iotstack flash failsafe /dev/ttyUSB0           # Failsafe image only
  iotstack flash mmwave /dev/ttyACM0 --ota-only  # Skip recovery, OTA prod only
  iotstack flash threadrouter                    # Auto-detect all USB devices
