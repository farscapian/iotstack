iotstack ledlightstrip-s3-arduino -- LED Light Strip (XIAO ESP32-S3, Arduino)

XIAO ESP32-S3 WiFi addressable LED strip (SK6812 RGBW). [WARN] In development.
Experimental A/B counterpart to ledlightstrip-s3: same board and wiring, but drives
the strip with neopixelbus on the Arduino framework (the combo neopixelbus supports;
it will NOT build under esp-idf). Use it to compare neopixelbus vs esp32_rmt_led_strip
on real S3 hardware.

Config: yamls/ledlightstrip-s3-arduino.yaml
Chip: esp32s3
Framework: arduino (neopixelbus)
Network: WiFi
Data pin: D0 = GPIO1

Commands (shared help for flash, update, reassign, verify):

  iotstack flash ledlightstrip-s3-arduino /dev/ttyACM0
  iotstack update ledlightstrip-s3-arduino
  iotstack update <MAC> ledlightstrip-s3-arduino
  iotstack reassign <MAC> ledlightstrip-s3-arduino
  iotstack verify ledlightstrip-s3-arduino

General command reference:

  iotstack flash help
  iotstack update help
  iotstack reassign help
  iotstack verify help
