iotstack sendspinspeaker -- SendSpin Speaker

ESP32-S3 WiFi audio / notification speaker device.

Config: yamls/sendspinspeaker.yaml
Chip: esp32s3
Network: WiFi

Commands (shared help for flash, update, reassign, verify):

  iotstack flash sendspinspeaker /dev/ttyACM0
  iotstack update sendspinspeaker
  iotstack update <MAC> sendspinspeaker
  iotstack reassign <MAC> sendspinspeaker
  iotstack verify sendspinspeaker

Examples:

  iotstack flash sendspinspeaker /dev/ttyACM0
  iotstack update sendspinspeaker --dry-run

General command reference:

  iotstack flash help
  iotstack update help
  iotstack reassign help
  iotstack verify help
