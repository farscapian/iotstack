iotstack ledlightstrip — LED Light Strip

ESP32-S3 WiFi addressable LED strip (SK6812).

Config: yamls/ledlightstrip.yaml
Chip: esp32s3
Network: WiFi

Commands (shared help for flash, update, reassign, verify):

  iotstack flash ledlightstrip /dev/ttyACM0
  iotstack update ledlightstrip
  iotstack update <MAC> ledlightstrip
  iotstack reassign <MAC> ledlightstrip
  iotstack verify ledlightstrip

Examples:

  iotstack flash ledlightstrip /dev/ttyACM0
  iotstack update ledlightstrip --dry-run
  iotstack reassign a1b2c3 ledlightstrip

General command reference:

  iotstack flash help
  iotstack update help
  iotstack reassign help
  iotstack verify help
